# Repository guidance

Read affected modules before editing. Preserve public API compatibility and existing issued credentials. Defaults are neutral and configurable. Mutating WG/AWG/Xray operations share devices.backend_lock with directory sync; Xray apply validates and rolls back on failure. Directory lookup errors never disable users.

Install only through the supported deployment roles. Do not flush firewall rulesets. Keep secrets and operational inventories outside distributed artifacts. English is canonical; update both local UI catalogs. Test fixes and validate the documented supported configuration on disposable VMs.
