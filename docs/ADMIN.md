# Administration

Use the emergency `admin` token to bootstrap identity, then create named administrators. Restrict emergency token access with `AUTH_LOCAL_ALLOWED_CIDRS`; store it in a password manager. Named API tokens are issued once and stored as hashes. `metrics` can only scrape metrics; `auditor` can only read or export audit. Users manage their own devices. Operators can issue, suspend, resume, revoke and assign devices subject to owner/profile limits. Administrators configure identity, profiles, routing and tokens.

In Local users, create a username, role and optional profile, then issue an invitation. Invitations expire after 72 hours, are single use and replace prior invitations. Passwords are 12–128 characters and are normalized to NFC and hashed with scrypt (N=131072, r=8, p=1). Local administrator enrolment requires TOTP by default (`AUTH_LOCAL_TOTP=admins`; alternatives `all` or `off`). Save the recovery codes at enrolment; they are each single use. Accepted TOTP time steps cannot be reused. A reset revokes password sessions and resets TOTP; issue it only after verifying the employee's identity. It does not revoke already issued VPN devices.

Group policies map exact directory groups to roles and profiles by priority. Qualified DNs, paths and DOMAIN\group names require an exact qualified match. Unqualified names intentionally match their group name. Use qualified policies to avoid two departments' identically named groups sharing privileges. A user explicitly disabled by an administrator stays disabled across subsequent directory logins.

Profiles define full or split routing, allowed corporate CIDRs, DNS, protocol choices, device limit and TTL. Full profiles permit public internet while corporate networks require explicit allowance. Split profiles permit only allowed ranges and DNS; an empty split profile blocks traffic. Client configs express the profile, and server policy enforces it even if a client changes its config. Full profiles include IPv6 default routes to prevent an IPv6 internet bypass; the gateway drops IPv6. Split mode intentionally keeps non-corporate internet local.

View Address pools before issuing large batches. WG/AWG pools have equal sizes and cannot overlap. Pool changes on an installed gateway fail before replacement. Revoke old devices to release addresses. Every device and directory change triggers policy refresh; policy diagnostics report failures. Diagnose Xray with its settings/doctor and routing preview/validation before applying changes.

The audit export endpoint `/api/auth/audit/export` returns JSON Lines, newest first, at most 1000 events per page. Follow `X-Next-Cursor` with `cursor`; optional `from_ts` and `to_ts` use UTC `YYYY-MM-DDTHH:MM:SSZ`. Retention defaults to 365 days. Export to a protected SIEM before retention removes events. Syslog output is optional and supports the local socket or UDP; use a local collector for authenticated TLS forwarding.

OIDC alone does not provide immediate directory offboarding. Its attestation policy defaults to 30 days and warns before expiry. Disable a user immediately through the administrative API when an IdP-only employee leaves; use LDAP reconciliation where automatic offboarding is required. SCIM is outside this release.
